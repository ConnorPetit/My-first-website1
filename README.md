# My-first-website1
Description of project

This is my portfolio website! The goal of this project was to create a functional website that displays our portfolio. I decided to go for a modernized layout, not too complex and not overly simple. I think these types of websites look the cleanest. My colors I decided to include were, white, black, light blue, and purple. Even though purple is my favorite color, I don’t like how it contrasts with some of the other colors on the website. So, I incorporated the purple into the hover links in my navigation. My typography is simple, Ariel is my favorite font to use, I think it looks clean and professional.  Some challenges I faced were making the carousel. When I originally did it the pictures kept messing with the layout and changing sizes, I struggled for a long time trying to figure out what was wrong. I changed the limit to how big the picture can be, although some pictures are a little cropped now. Another big challenge was JavaScript and making the carousel function properly. There is a lot that goes into it but some main things I changed were, adding the word “active”, 5000 ms to change the slide every 5 seconds, and changing the loop.
